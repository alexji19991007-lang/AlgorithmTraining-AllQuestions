# Algorithms_Training
Practice Makes Perfect!

This is a collection of algorithm problems that you may meet during an interview. The files does not contain problem descriptions (I may try to include this in the future if I got time), so it's your job to find what problem it is solving, but the file name may have already described the nature of the problem.

For beginners, please look at modules with numbers marked at the beginning first as those problems will help you build your foundations for algorithm interviews. After finishing studying those problems, please check the Miscellaneous modules for more problems. 

Note that there might be numerous repetitions between them, so when you encounter different solutions to the same problem, please refer to numbered modules as authentic solutions. Also, I have used the Stack class in some of my solutions. Please notice that Stack is a deprecated class in Java, so please use Deque<Type> mStack = new ArrayDeque<>() / new LinkedList<>(); instead. The offerFirst(), peekFirst() and pollFirst() APIs will do the job for a stack.

I will be updating this repository on a regular basis, so please check my latest commits.
